# Clone a voice

From a recording to a voice you can use by name, in four commands. Everything
runs on your machine; no audio leaves it.

```bash
qvox setup                                          # 1. check this machine can run it
qvox voice add ana ~/Downloads/voice-note.ogg      # 2. turn a recording into a voice
qvox voice test ana                                # 3. hear it
qvox speak "Hola, ¿cómo va?" --clone ana -o hi.wav # 4. use it (or "clone": "ana" in the API)
```

## Before you start

### Requirements

Check these first — `qvox setup` does it for you and says plainly whether this
machine is worth the download.

| | Recommended | Works, slowly | Not enough |
|---|---|---|---|
| Hardware | Apple Silicon (M1 or newer) or an NVIDIA GPU with 8 GB+ VRAM | Any other CPU (about 10x slower than real time) | — |
| Memory | 16 GB RAM | 8 GB | less than 8 GB |
| Disk | 15 GB free for the models | — | less than 15 GB |
| Software | Node 18+, [uv](https://docs.astral.sh/uv/), [ffmpeg](https://ffmpeg.org/download.html) | — | no Node 18 or no uv |

For reference: on an M4 Pro with 24 GB, a cloned voice renders a 25 s line in
about 17 s. The first request after starting also loads the model (a few
seconds more).

### Consent

Cloning copies a real person's voice. **Only clone your own voice, or one whose
owner gave you permission.** A synthetic voice (from ElevenLabs or similar) is
licensed by whoever made it — check the licence allows reuse. Never use a clone
to impersonate someone or to deceive. `qvox voice add` asks you to confirm this
every time (or pass `--consent`).

## 1. Get a recording

The clone copies *everything* in the reference: the room, the hiss, and above
all the delivery. A flat recording makes a flat voice no matter what you ask it
to say. Aim for **25-40 seconds of one person talking naturally**.

### Option A — record yourself (best)

- **Anything works as a microphone**: a phone voice memo, QuickTime
  (File > New Audio Recording), a headset. Keep it about 20 cm away.
- **Quiet room, no music, no echo.** A room with curtains or a closet full of
  clothes beats a bare kitchen.
- **Stand up and talk to someone**, not at the microphone. Energy is audible.
- **Say something real.** "This is a test to clone my voice" produces a
  self-conscious, monotone clone — the single most common mistake.
- **Vary the intonation on purpose**: a question, an exclamation, a short
  sentence between long ones. Don't restart if you stumble; carry on.
- **Include the words it will have to say** — product names, jargon — so it
  learns your pronunciation of them.

Read one of these aloud (about 35 s each), or say something of your own:

> **Español** — Hola, ¿qué tal? Te cuento cómo es mi día. A la mañana, antes
> que nada, un café bien cargado; sin eso no arranco. Después reviso los
> pendientes y elijo uno solo para empezar, porque si intento todo a la vez no
> termino nada. ¿Y a la tarde? Depende. A veces reuniones, a veces silencio
> total para concentrarme. Lo que nunca falta es una caminata corta. Así de
> simple. ¡Y funciona!

> **English** — Hi, how's it going? Let me tell you about my day. First thing
> in the morning, before anything else, a strong coffee — I don't start
> without it. Then I look at what's pending and pick just one thing, because if
> I try everything at once I finish nothing. And the afternoon? It depends.
> Sometimes meetings, sometimes total silence to focus. What never changes is a
> short walk. That's it. And it works!

### Option B — a recording you already have

A voice note (WhatsApp, Telegram), a podcast clip, the audio of a video — any
file ffmpeg reads (`.ogg`, `.m4a`, `.mp3`, `.wav`, `.mp4`, `.mov`…). Phone voice
notes are noisy and band-limited; `voice add` cleans them, but a clean
recording will always clone better.

If the good part is in the middle, point at it:

```bash
qvox voice add ana interview.mp4 --start 95 --length 35
```

### Option C — from a URL (your own content)

With [yt-dlp](https://github.com/yt-dlp/yt-dlp) installed, `voice add` downloads
the audio for you. Use it for your own videos or content you have the rights
to:

```bash
qvox voice add ana "https://www.youtube.com/watch?v=..." --start 60 --length 35
```

### Option D — a synthetic voice you licensed

A voice generated by another TTS service can be cloned like any recording.
Generate 30-40 s of natural, varied speech with it (the Spanish text above
works), download the file, and add it. Check that the service's licence lets
you reuse that voice.

## 2. Prepare it: `qvox voice add`

```bash
qvox voice add <name> <file|url> [--start s] [--length s] [--clean auto|strong|light|off] [--consent]
```

It measures the recording, cleans it only as much as it needs, cuts it to at
most 40 s, normalises the level and saves a 24 kHz mono reference in
`~/.qvox/voices/<name>.wav` (plus a `.json` with what was done). Then it tells
you whether the result is worth using:

```
  voice      ana  ->  ~/.qvox/voices/ana.wav
  length     37.4 s  (from 0 s of voice-note.ogg)
  clean-up   strong
  voice/noise 26 dB  ->  59 dB   (higher is better, aim for 40+)
  levels     speech -15 dB, room -74.1 dB
  verdict    GOOD
```

| Verdict | Meaning |
|---|---|
| **GOOD** | Clean, long enough. Use it. |
| **USABLE** | It works; the warnings say what would make it better. |
| **POOR** | It will clone badly. Fix the warning and add it again. |

What the warnings mean:

- **too short / short** — under 8 s the model barely has a voice to copy; aim
  for 25-40 s of continuous speech.
- **trimmed to 40 s** — longer is not better (energy drops); use `--start` to
  keep the liveliest part.
- **the original clips** — the recording hit 0 dB and distorted. Record further
  from the microphone or lower the input gain. Clean-up cannot undo clipping.
- **background noise remains** — the room is too present even after clean-up.
  Record somewhere quieter.
- **very quiet original** — speak closer to the microphone.

`--clean auto` (the default) picks the clean-up by how far the voice stands
above the room: a phone note gets the strong chain (noise reduction, gate), a
clean studio take only a light filter — denoising clean audio smears the voice.
Force one with `--clean strong|light|off`.

## 3. Test it

```bash
qvox voice test ana                       # a sample line in your default language
qvox voice test ana "Any text you like" --lang Spanish
```

The result goes to `~/.qvox/out/voice-ana.wav`, already at a normal listening
level (raw clone output is quiet). Listen for:

- **It sounds robotic or flat** — the reference is flat. Record again with more
  energy and variation; nothing downstream fixes delivery.
- **Hiss or room tone** — use a quieter recording (or `--clean strong`).
- **Wrong accent** — the reference has too little speech, or mixes voices.

## 4. Use it

```bash
qvox speak "Texto" --clone ana -o out.wav
```

```bash
curl -X POST http://127.0.0.1:5111/v1/audio/speech \
  -H "content-type: application/json" \
  -d '{"input":"Hola, ¿cómo va?","language":"Spanish","clone":"ana"}' -o out.wav
```

In the web panel, pick it from **Cloned voices**. `GET /v1/voices` lists them
under `cloned`.

Tips for longer narrations:

- **Send the whole script in one request.** The engine splits it by sentence and
  keeps the prosody flowing; one request per line sounds clipped and mechanical.
- **Normalise the output** before mixing it into a video:
  `ffmpeg -i raw.wav -af "loudnorm=I=-16:TP=-1.5:LRA=11" out.wav`
- A cloned voice **cannot be directed** with `instruct` or `[emotion]` tags —
  its tone comes entirely from the reference. For a livelier clone, record a
  livelier reference.

## Managing voices

```bash
qvox voice list            # name, length, verdict, source
qvox voice remove ana
qvox voice path            # the folder (you can also drop a 24 kHz wav in by hand)
```
